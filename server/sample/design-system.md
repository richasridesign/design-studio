# Design system profile

Libraries: Grocery UI Kit

## Colors
- Brand/Primary: #1c7c54 (variable color/brand/primary)
- Brand/Primary dark: #145a3d (variable color/brand/primary-dark)
- Surface/Default: #ffffff (variable color/surface/default)
- Surface/Cream: #faf6ee (variable color/surface/cream)
- Text/Primary: #1e1e1e (variable color/text/primary)
- Text/Secondary: #5f6368 (variable color/text/secondary)
- Border/Default: #d9d9d9 (variable color/border/default)
- Feedback/Error: #c62828 (variable color/feedback/error)
- Feedback/Success: #2e7d32 (variable color/feedback/success)

## Text styles
- Heading/L: Inter 28px 700 line 36
- Heading/M: Inter 20px 600 line 28
- Body/Regular: Inter 16px 400 line 24
- Body/Small: Inter 14px 400 line 20
- Label/Button: Inter 16px 600 line 20

## Spacing
4, 8, 12, 16, 24, 32, 48

## Radius
4, 8, 12, 999

## Components
- Button (key a1f3c0): Primary, Secondary, Ghost, Disabled
- Input (key b27d41): Default, Focused, Error, Disabled
- List item (key c93e5a): Default, With image, With action
- Stepper (key d41b7e): Default, Min, Max
- Banner (key e58a92): Info, Error, Success

## Rules
- Primary button only once per screen
- Use color variables, never raw hex values
- Text on Surface/Cream must reach 4.5:1 contrast
- Touch targets are at least 44px
- Spacing comes from the spacing scale
